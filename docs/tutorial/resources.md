# Resources

There are other addons that can be useful in a 2D animation workflow.

## Addons

### Grease Pencil Tools

The **Grease Pencil Tools** addon is available on the extensions platform.

Here is the [Addon page and documentation on the extension platform](https://extensions.blender.org/add-ons/grease-pencil-tools/).

It adds some quality of life tools:

- Canvas rotation via a shortcut: `Ctrl + Alt + Mid Click`
- Box deformer: `Ctrl + T`
- Timeline scrubbing in viewport: `Alt + Mid Click`
- Quick layer navigator: `Y` (continuous press)
- Straighten Stroke

> Recommended for both 2D animation and Storyboard workflow.

### GP Toolbox

The **GP Toolbox** addon is an internal tool of [Autour du Volcan](https://advstudios.fr/) studio and is publicly available.

You can get [GP Toolbox on this repository](https://git.autourdeminuit.com/autour_de_minuit/gp_toolbox).

It adds a lot of Grease pencil related features, including the `Draw cam` method, allowing rotation within the camera view without affecting the real camera transformation.

Here is a [demo video](https://www.youtube.com/watch?v=Htgao_uPWNs) (not covering everything).

> Recommended mainly for 2D animation workflow, but storyboard as well.

### Push To Talk

**Push to Talk** allows for "_Convenient recording of scratch dialog for an edit_" during playback by pushing a button in the sequencer header.

Get the addon on the [Push to Talk repository](https://github.com/britalmeida/push_to_talk).

Made by [Inês Almeida](https://github.com/britalmeida) and contributors.

> Recommended to add quick test dialog/fx on a shot. Helps to validate action timing and see if the intention feels right.

### NijiGPen

**NijiGPen** adds advanced functionality for stroke cleaning, coloring and more.

Get the addon and check the documentation on the [NijiGPen repository](https://github.com/chsh2/nijiGPen).

Made by [Chaosinism](https://twitter.com/chaosinism).

> Recommended if you need line polishing or advanced coloring features.
