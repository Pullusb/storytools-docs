
# Installation
> How to install software and addons

Note that everything is also detailed on the [Setup Project](tutorial/setup-project.md) page.

## Blender

You need the software [Blender](https://www.blender.org/), preferably the latest stable version.


## Storytools addons

<!-- (or [SPA build](https://the-spa-studios.github.io/blender-spa-userdoc/) Windows only) -->

Storytools is available on the [official storytools repository](https://github.com/Pullusb/storytools).

Starting with Blender 4.2, you can simply drag and drop the downloaded zip file onto the Blender window for installation.

For Blender versions _before_ 4.2, see this tutorial on [how to install Blender addons](https://github.com/Pullusb/How_to_install_Blender_addons).


## Sequencer tool

Storytools only takes care of object management and controls in the viewport.

It's already useful for general 2D animations, but for a full storyboard setup, it needs to be used in tandem with another addon to handle sequence and shot management.

Though you can use any other means for shot management, the **Spa-sequencer** addon, created at SPA Studios, will be referenced in this documentation. More information about it can be found on the [shot management page](tutorial/shot-management.md).

It is preferable to use **SPArk**, a more up-to-date fork that works better with standard Blender.  
[Get SPArk here](https://github.com/NickTiny/SPArk-sequencer-addon)
